# ATM-Machine
The primary actor is the Customer, who performs operations such as entering a card, entering a PIN, authenticating, and performing various transactions like cash withdrawal, fund transfer, balance check, deposit, and PIN renewal. Each of these actions is part of the “Perform Transaction” use case. The Bank System acts as an external system that interacts with the ATM Machine to update balances and authorize transactions, ensuring secure and accurate processing of customer requests. The Technician is responsible for refilling cash and maintaining the ATM machine, ensuring it functions properly. The Bank Admin oversees the system by generating reports and monitoring transactions to maintain operational efficiency and detect any irregularities. Overall, the diagram provides a clear depiction of how different users interact with the ATM system to manage and support banking transactions securely and efficiently.
